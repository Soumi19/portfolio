# Off-page SEO & backlinks (white-hat, realistic)

Code cannot create backlinks. This is the checklist that actually moves rankings. Do the first block first; it takes about an hour.

## 1. Profiles you already own (add the website URL + same name/headline everywhere)
- LinkedIn (Contact info -> Website, Featured section -> portfolio + best article), Medium bio, GitHub profile + pinned repo READMEs ("Portfolio: <url>"), Muck Rack.
- Use one consistent line: "Technical Content Writer · Data & AI · Web Solutions — <url>".
- Add Upwork / Fiverr / Contra / Clutch-style freelance profiles only if you really use them; they are mostly nofollow but build brand + entity signals.

## 2. Make Medium work for the site
- Each Medium article: add "Originally part of my portfolio -> <article page on your site>" or link to /writing/ in the footer note. Medium links to you pass reader traffic and brand mentions.
- Keep article canonicals pointing to Medium (already done) to avoid duplicate-content issues.

## 3. Earn editorial links
- Guest-write for relevant publications (data science, technical writing, EdTech, research-skills blogs). One real bio link beats 100 directory links.
- Publish 1 original, citable asset per month on the site (e.g. "How I structure a literature review", a small dataset analysis with chart). Original data/visuals get cited.
- University / library "research support" resource pages: politely suggest your free explainers if they genuinely fit.
- Answer questions on Reddit/Quora/StackExchange with real help; link only when it adds value and rules allow.

## 4. Brand + local signals
- Google Business Profile as a service-area business (only if eligible and you can verify it).
- Same NAP/name everywhere; keep "Based in India, working remotely" wording (no fake offices).

## 5. Avoid
Bought links, PBNs, mass directory submission, comment spam, fake reviews. They can cause manual actions.

## 6. Track (monthly)
Search Console (queries by country: UK, US, Kuwait, NZ, IN), Bing Webmaster, referring domains (free: Ahrefs Webmaster Tools). Update the services pages with the queries that start getting impressions.
