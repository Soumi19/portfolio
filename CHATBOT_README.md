# Free portfolio chatbot

A cartoon robot button opens an accessible, responsive assistant on every page. It gives predefined, topic-matched answers about the portfolio and links to the correct services and contact pages. It does not send messages to Soumi, store chats, call an AI model, or answer arbitrary general questions. Contact links open the existing enquiry page.

Edit portfolio-chat.js topics to update answers. The assistant explicitly discloses that it is an automated portfolio guide. No API key, paid service or backend is required. No live AI integration is configured; adding one requires a separate secure backend endpoint and provider credentials kept outside the public repository. GitHub Pages alone cannot keep an API key secret.
