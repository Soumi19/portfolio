# Publishing and search visibility

1. Deploy this complete package using the included GitHub Pages workflow.
2. Confirm site.config.json uses the final HTTPS website address.
3. Verify ownership in Google Search Console and Bing Webmaster Tools. Submit sitemap.xml at the final website URL. These steps require your accounts.
4. Add the portfolio URL to your real LinkedIn, Medium, Muck Rack and GitHub profiles. Request relevant editorial/project credits from genuine collaborators where appropriate. No external backlinks have been created by this code update.
5. Publish original research guides and documented projects based on work you can substantiate. Update service pages as your offering changes.
6. Monitor search queries, enquiries and page experience after launch; refine copy with actual Search Console data. No search-volume research or ranking guarantee is included.

Student pages describe guidance, draft feedback, editing, referencing and analytical support. They do not promise grades or submission-ready work written on a student's behalf. International service language describes remote availability, not unverified overseas offices.
