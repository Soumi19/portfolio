Manrope and Portfolio Text web fonts

Manrope by The Manrope Project Authors. Portfolio Text is a Latin and Greek subset derived from Source Sans 3 by Adobe, with primary font names changed. Copyright notices and SIL Open Font License files are included. Font outlines have not been redesigned.

Portfolio Display is a Latin subset derived from Sora. Primary font names have been changed; outlines have not been redesigned. Original copyright and SIL Open Font License are included.

Fraunces (headings) is the variable font by Undercase Type, Latin subset from @fontsource-variable/fraunces, SIL Open Font License (see fraunces-OFL.txt). Weight 100-900 and optical-size axes.
Typography roles: Fraunces = headings; Portfolio Text (Source Sans 3) = body text; Manrope = buttons, navigation, chips and labels.
